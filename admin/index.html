Change an expedition code

Pick the expedition, type its current code and the new one. This page makes a new version of the expedition page locked with the new code. Everything happens on this device; codes are never sent anywhere.

1Expedition
2Codes

Codes ignore capital letters, spaces and dashes: assam-2026 and ASSAM 2026 are the same code. Use at least 6 characters.

3Upload it
  1. Download the new page: Download index.html
  2. On GitHub, open the expedition’s folder and choose Add file → Upload files.
  3. Drop in the downloaded index.html (it replaces the old one) and press Commit changes.
  4. After a minute or two the new code works. Travelers who saved the old code will be asked for the new one.
